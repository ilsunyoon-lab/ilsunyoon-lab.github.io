# 연구실 사진 폴더

이 폴더에 사진을 올리면 홈페이지 "연구실 일상" 섹션에 자동으로 나타납니다.

## 파일 이름 규칙

`날짜_설명.jpg` 형식으로 저장하세요. 날짜는 사진 위에, 설명은 사진 아래에 표시됩니다.

- `2026-05-20_대한화학회 춘계학술대회.jpg`
- `2026-03-02_새 학기 연구실 MT.jpg`
- `2025-10-01_라만 분광기 실습.png`

최신 날짜가 맨 앞에 나옵니다. jpg, png, webp, gif 파일을 쓸 수 있습니다.

## 올리는 방법

1. 이 폴더(photos)에서 **Add file → Upload files**를 누릅니다.
2. 사진을 끌어다 놓고 **Commit changes**를 누릅니다.
3. 1~2분 뒤 홈페이지를 새로고침하면 사진이 보입니다.

사진 한 장은 2MB 이하로 줄여 올리면 홈페이지가 빨리 열립니다.
